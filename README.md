## Versions and loaders

Use one repository, with a separate branch for each loader and Minecraft version: `fabric/<minecraft>`, `neoforge/<minecraft>`, and `forge/<minecraft>`. Each published binary has an immutable tag in the form `v<mod-version>-mc<minecraft>-<loader>`.

`main` contains the maintained **NeoForge 1.21.1 / 21.1.265 / mod 1.18.79** source plus this version index. The original uploaded 1.18.78 source is preserved at [`v1.18.78-mc1.21.1-neoforge`](https://github.com/Guko-ru/MDK-Cosmetic/tree/v1.18.78-mc1.21.1-neoforge).

An em dash means no stable/recommended target was selected for that loader. Fabric builds require the matching Fabric API listed in `build-info.json` and the release notes. Loader version numbers are independent of the mod version: Fabric uses mod 1.18.78; the supplied NeoForge 1.18.79 source is the basis for NeoForge and Forge builds.

## Build

Use **JDK 21** for Minecraft 1.21.x and **JDK 25** for Minecraft 26.x. Switch to the branch for your intended target before building. On Windows run `build_mod.bat`; with Gradle installed, run `gradle --no-daemon clean prepareRelease`. The release JAR is written to `build/release/`.

`src/` contains runtime code, resources, and separate validation fixtures. `blockbench/` contains editable models and is excluded from runtime JARs. Keep historical item and registry IDs intact when updating existing worlds, including `mdkcosmetic:collector_pickaxe` for the Collector's Multitool.

## Validation

All 36 selected targets were built and checked in their own client and server. Checks covered all 1208 item models, both creative tabs, two assembled machine tiers at four GUI/window configurations, real inventory and memory slot clicks, and both boss phases. The boss starts black with black effects, then copies its opponent's skin and equipment in phase II.

Custom hats no longer inherit the solid vanilla helmet cube. Three-actor visual checks covered custom hats, dye colors, glint, and diamond trims; deferred renderers preserve independent poses. New Forge targets also verify all nine chest loot modifiers and the original Collector book chance.

JEI integration is optional. Forge JEI API is published for 1.21.1; integration sources are retained but excluded on Forge targets without a published API. Per-target build information and artifact SHA-256 hashes are in `builds.json` and each branch's `build-info.json`.

The legacy spawn egg sprites retained for compatibility are Minecraft artwork by Mojang/Microsoft; their rights remain with their owners. Other applicable third-party licenses remain unaffected.
